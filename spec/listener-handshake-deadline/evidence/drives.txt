# CLI drives on the branch (P3 verify), 2026-11-14

Each drive runs in a throwaway site via `.agents/factory/bin/temp_site.sh uv run python
"<worktree>/spec/listener-handshake-deadline/research/drive.py" SCENARIO ...`, holds one TCP connection
that never sends a byte to the server's queue port, and stops every process it started by PID
("stopped pid ..."). Older clients come from PyPI in scratch environments: 2.9.0a8 and 2.8.7
(CPython 3.14.6). Paths and the host name are replaced by placeholders.

Summary: all 8 drives pass. Default deadline: the held connection stays open while hs server,
hs cluster (local) and the hs relay site-local server serve the work. --handshake 2: each closes it
2.0 s after it connected, with one WARNING naming server.tls.handshake. A 2.9.0a8 client runs the
tasks; a 2.8.7 client connects, completes TLS, authenticates and is refused as too old (exit 5), as
on develop.
